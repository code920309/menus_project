메뉴 등록 파일 업로드 작업 기록
================================

수정한 파일과 목적
------------------

1. components/MenuInputForm.js
   - 메뉴 등록 폼에 파일 선택 입력을 추가했습니다. 전송 필드명은 "file"입니다.
   - 폼의 메뉴 정보와 선택 파일을 FormData로 묶어 등록 API에 전달합니다.
   - 기존 신규 메뉴 ID 값 0을 유지하고, 파일을 선택하지 않은 경우 빈 파일 값은 제외합니다.
   - 등록 성공 시 알림을 표시하고 메뉴 목록 화면으로 이동하는 기존 동작은 유지합니다.

2. services/api.js
   - addMenu가 FormData를 받으면 multipart/form-data 본문으로 전송하도록 수정했습니다.
   - multipart 요청의 Content-Type은 브라우저가 boundary와 함께 설정하도록 직접 지정하지 않습니다.
   - 기존 JSON 객체를 전달하는 경우에는 JSON 요청 방식도 유지합니다.
   - 백엔드에서 POST /menus가 메뉴 필드와 선택적 "file" 업로드를 수신하고 저장해야 한다는 점을 코드 주석으로 표시했습니다.

백엔드 작업은 이번 변경에 포함되지 않았습니다. 실제 파일 업로드를 완료하려면 백엔드가 multipart/form-data를 처리하고, 파일 필드명 "file"을 프론트엔드와 동일하게 사용해야 합니다.
